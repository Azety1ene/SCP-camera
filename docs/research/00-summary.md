## 1. 骨格:どの作品にも共通する組み立て

1. **平凡な見た目・安全宣言から入る。** 「害はない」「普通の◯◯である」と書いてから異常を明かす(1048, 2295, 1471, 529)
2. **ルールを先に、理由は後に。** 奇妙な収容手順を先に見せ、なぜそうするのかは説明の後半で分かる(1609, 173, 040-JP)
3. **情報は段階的に積む。** 「ルール → 反復される事例 → 最大の事件 → 手記・注記で感情」(243-JP, 120-JP, 268-JP, 294)。事例は軽いものから重いものへ、無生物から人へ、と段階を上げる(261, 914)
4. **本文は冷たく、感情は周辺に置く。** 地の文は推定の語尾(「〜と考えられています」)で淡々と書き、感情は脚注・注記・手記・手紙・会話に任せる(458, 2295, 243-JP, 120-JP, 544-JP)
5. **最後の一文で読後感を決める。** 手紙(2295)、消された一行(120-JP)、読者への呼びかけ(1342)、視線の反転(1981)、手記の問いかけ(243-JP)、一行の断定(062-JP)

## 2. 伏せ方の使い分け

| 使い方 | 効果 | 例 |
|---|---|---|
| 人名・日付・地名を██にする | 報告書らしさ(基本の伏せ) | 全般 |
| 最悪の結果だけ伏せ、その一段手前は具体的に書く | 想像させて怖さを増す | 914 |
| 物語の核心を伏せ、上位クリアランスで開示 | 段階的な開示、真相の特権感 | 1981, 1000, 062-JP |
| 伏せ字そのものを笑いや切なさにする | 「そこを伏せるのか」という笑い、消された言葉の切なさ | 120-JP, 1045-JP |
| 情報が無いこと自体を見せる | 不在による不気味さ | 444-JP(クラス未割当), 240-JP(データ破損) |
| 名前は伏せても台詞は見せる | 匿名のまま人物の温かさを伝える | 243-JP |

**数値は具体的に、固有名詞は伏せる**のが基本(寸法、時間、距離、回数は細かく書く)。

- インタビュー・聴取記録 — 096, 2006, 120-JP
- 事案記録・探査ログ(時刻付き)— 087, 2935, 544-JP
- 第三者の手記 — 243-JP
- 手紙・カード — 2295, 120-JP
- 製品文書・広告・取扱説明書 — 1471
- 改訂前の版・廃止された旧プロトコル — 1045-JP, 100-JP, 2000-JP
- 添削・注記が重なった文書 — 1045-JP
- 対象 / 結果の表 — 458, 120-JP

- 公的書式(判決文、開発資料、管理票)— 062-JP, 240-JP

## 4. 読後感の型(実際の作品で確認できたもの)

| 型 | 決め手 | 例 |
|---|---|---|
| ほっこり・癒し | 短い記述、世話の細かい指示で愛着 | 529, 999 |
| 笑い → 切なさ | 笑いを積んで、最後に私的な一言 | 120-JP, 458, 1045-JP |
| 切なさ・温かさ | 冷たい実験記録と、感謝・手紙の対比 | 2295, 243-JP, 1342 |
| じわじわ来る不安 | 時間経過による段階的なエスカレーション、数値の欠落 | 1471, 240-JP, 087 |
| ホラー | 愛らしさ・生活感からの裏切り | 1048, 002, 096, 2935 |
| ルール型の緊張 | 破ってはならない手順を読者に追体験させる | 173, 040-JP |
| 謎 | 仕組みを「未解明」のまま残す、否定の積み重ね | 055, 914, 087 |
| スケールの飛躍 | 管理 → 内部 → 外部 → 宇宙、と規模を広げる | 100-JP, 3008 |
| どんでん返し・評価の反転 | 前の記述の訂正、改題、因果の遅延 | 1000, 268-JP, 1609 |
| 読者を巻き込むメタ | 閲覧警告、本文への割り込み、「読んだ時点で手遅れ」 | 040-JP, 444-JP, 1981 |

生成のたびにサーバー側で型を1つ選んで指示する。笑いだけでなく、全体の半分以上は物語寄りの型にする。

## 5. このアプリに直結する技法

- **写真の端・背景・反射に「何かが写っている」と書く**(1471)。読者が自分の撮った写真を見直したくなる
- **写真から拾った具体的な特徴を、数値や物証にする**(2935, 1342)。色、傷、印字、周囲の物、写り込んだ時計など
- **撮影日時をわざと壊す・矛盾させる**(2000-JP)。「信頼できない数値」として異常の一部にする
- **撮影した写真を「添付資料」として報告書に組み込む**。画像のキャプションも報告書の一部として生成する
- **物自身の一人称**(426)を、補遺の形式の選択肢に入れる
- **クリアランスによる段階的な開示**(1981, 1000, 062-JP)を、O5機能の設計にそのまま使う。レベル2では謎のまま、O5では「前の記述は偽情報だった」と明かされる、など
- **日本の生活の定型文を異常の媒体にする**(544-JP の館内放送、062-JP の判決文、240-JP の開発資料、1045-JP の添削)

## 6. 日本支部らしさ

- 日本の生活と制度に根ざした題材(百貨店、学校、公衆電話、古い家、消防、役所の書式)
- **言葉遊びのある題名を付ける**(「お眼鏡にはかなわない」「0匹のイナゴ」「伊れない病」)。JPの記事には番号だけでなく題名がある
- サイト番号は `サイト-81██`、地名は `██県██市`
- 独自の用語(Dクラス職員、記憶処理、ヒューム値、クリアランスレベル)
- 子どもや無垢な存在のひらがな口調と、報告書の硬い文体の対比(2000-JP, 120-JP)
- 日本語の音や文字の性質を仕掛けにする(161-JP)

## 7. 生成で禁止・配慮すること

- 自殺・自傷・いじめ・性的な描写・過度なゴアは題材にしない(1045-JP や 1048 のような要素は扱わない)
- 実在の人物を登場させない(1981 は実在の大統領を素材にしているが、このアプリでは避ける)
- 写真に写った人を特定したり、容姿を貶めたりしない
- 既存記事の文章や固有の設定(既存のSCP番号、要注意団体)はそのまま使わない。財団の一般的な用語(Dクラス、O5、サイト、記憶処理など)は使ってよい
- 真顔を崩す表現(「面白いことに」、絵文字、「!」の多用)は使わない

## 8. 出力スキーマへの反映

前回の案に、次を追加する。

- **題名**(言葉遊びを含む日本語の題名)
- **補遺の形式**(3. のレパートリーから1〜2個)
- **脚注**(感情や補足を置く場所)
- **添付資料のキャプション**(撮影写真の説明。写り込みへの言及を含む)
- **最後の一文**(読後感を決める一文を明示的に生成させる)
- **O5開示の内容**(レベル2で伏せた核心と、O5限定の補遺)

分量は、実際の記事より短い**1,500〜2,500字程度**を目安にする。スマホで最後まで読める長さに抑える。
