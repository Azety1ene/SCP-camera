# EN翻訳版(深く分析)A:日常の物

出典:SCP財団 日本語Wiki(http://scp-jp.wikidot.com/)、CC BY-SA 3.0。本ノートは技法の分析であり、引用は1文以内にとどめている。

## SCP-261 異次元自販機
- **基本:** Safe。番号を入力して硬貨を入れると、ランダムな商品が出てくる黒い自販機。出所不明の、異常なものを含む商品が出る
- **構成:** 収容プロトコル(承認制、1日10回まで、金額の上限)→ 説明(発見の経緯、外観、仕組み)→ 販売物の調査ログ → 「続きは実験記録へ」
  - ログの並びは「普通の飲料 → 存在しないフレーバー → 食品として不可解なもの → 他のSCPの製品 → 人命に関わるもの」と、**段階的に危険度が上がる**
- **伏せ方:** 黒塗りはほとんど使わない。代わりに「詳細不明」「未知の言語でパッケージング」で中身を隠す。実在のブランド名を出したうえで「この会社はこのフレーバーを生産していません」と否定し、現実味を出す
- **読後感:** 不気味さ。存在しない味などの軽い笑いの後に、商品リストの途中で爆発と死者が一行で入る落差。最後は「柑橘系の匂い」という小さな異常で余韻を残す
- **文体:** 「〜と評価されました」「〜と判明しました」の調査報告調。数値が具体的(金額、秒数、重さ)
  - 「SCP-261には、いかなるマークも製造番号も記載されていません。」
- **応用:**
  - 規則(承認条件・上限・禁止事項)を先に示し、その外側で異常を見せる
  - 「普通 → 偽物 → 異常 → 危険」とエスカレートするリスト
  - 実在の製品カテゴリを使い、「そんな製品は存在しない」と否定して現実味を出す
  - 最後は大事件ではなく、小さな異常で締める

## SCP-294 コーヒー自動販売機
- **基本:** Euclid。液体の名前を入力すると、その液体が紙コップで出てくる自販機
- **構成:** 収容プロトコル → 説明(仕様、試験数、使用回数の制限)→ 設置の経緯 → 事案記録 → 付録群 → 承認待ちの注記
  - 付録は「研究員は『〇〇を1杯』と注文した → 結果 → 考察」という**同じ型の反復**
  - 事案(危険な結果)を付録より前に置くので、読者は危険を知ったうえで軽い実験を読むことになる
- **伏せ方:** 人名・部署・SCP番号は伏せる。一方で、何が起きたかは生々しく書く。「誰が」は匿名、「何が起きたか」は具体的
- **読後感:** 笑い・怖さ・切なさの混在。抽象的な注文を文字通りに解釈した出力で笑わせ(「私を驚かせて」→ 沸騰したお湯)、同じ型のまま死や人生の重さを一行で置く
- **文体:** 「〜しました」「〜と推察されます」。注文は「」で囲み、結果を別の行に書く。ある博士が自分の人生を振り返り、自叙伝を持って戻ってくる、という私情が淡々と書かれて切なさが増す
- **応用:**
  - **「入力 → 出力 → 考察」の反復テンプレート**
  - 抽象的な言葉を文字通りに解釈すると、コメディと不気味さが同時に出る
  - 取り返しのつかない結果は、感情を交えず事務的に一行で書く
  - 付録を増やして「まだ調査中」の厚みを出す

## SCP-914 ぜんまい仕掛け
- **基本:** Safe。巨大なぜんまい仕掛けの装置。物を入れてダイヤル(Rough / Coarse / 1:1 / Fine / Very Fine)を選ぶと、物を「改造」して出す
- **構成:** 収容プロトコル → 注意(生物の実験禁止)→ 説明(仕組み、ダイヤル)→ 実験ログ(無生物中心)→ 人間を被験者にした実験の文書(死者、禁止の決定)→ 研究所長の注記
  - 「仕組み → 無生物の軽い実験 → 生物の重い実験 → 禁止」と、危険度の高い結果に段階的に近づく
- **伏せ方:** **最悪の結果だけを[削除済]にして、その一段手前は具体的に書く。** 内部の動作は「確認できていない」のまま
- **読後感:** 謎と怖さ。研究所長の「生きていない平凡な物なら自由に試していい」という軽い許可が、直前の死者の記録と並ぶことで、組織の無神経さが浮かぶ
- **文体:** ログは「入力: / 出力:」の二項目で統一。数値が非常に具体的(重さ、温度、抵抗値、被験者の身長体重)
- **応用:**
  - 「入力物 × 設定 → 出力」の対照表
  - 無生物 → 生物 → 人間、と対象のカテゴリを段階的に上げる
  - 最悪の結果だけ伏せる

## SCP-426 私はトースター
- **基本:** Euclid。普通のトースター。関わった人は「自分はトースターだ」と思い込むようになる。**報告書の全文がトースター本人の一人称**で書かれている
- **構成:** 収容プロトコル(一人称:「私は窓のない部屋に閉じ込められる」)→ 説明(自己紹介 → 能力 → 前の持ち主一家に起きたこと → 回収)→ 実験記録 → 博士の注記
- **伏せ方:** 名前と日付は伏せる。語り手の言葉の途中に[編集済]が入る箇所があり、語り手の不穏さが増す
- **読後感:** 不気味さ・ユーモア・切なさの混在。語り手の軽い口語と、淡々と並ぶ死の事実との落差
- **文体:** 本人は口語(「〜だよ」「〜んだ」)、職員の記録は事務調。**実験記録の中で、Dクラス職員の発言まで一人称に「感染」していく**。文書そのものが異常の影響を受けている仕掛け
  - 「こんにちは、私はSCP-426。誤解がないようこうして自己紹介させてもらうよ。」
- **応用:**
  - **物自身を語り手にし、口語で性格を与える**(写真の物に語らせる生成にそのまま使える)
  - 文書の形式そのものが異常の影響を受ける
  - 検閲を語り手の言葉の中に入れる

## SCP-458 はてしないピザボックス
- **基本:** Safe。触れた人の好みのピザが無限に出てくるピザの箱。サイトの食堂で無料で使われ、職員の士気が上がっている
- **構成:** 収容プロトコル(安全なので食堂に置く、の一行)→ 説明 → 試験の補遺 → 博士の注意書き → 他のSCPに試した反応の表 → 研究員の追記
- **伏せ方:** 控えめ。中身はほぼ具体的に書き、脚注で補足する。**隠すことで重さを出すのではなく、表に並べることで軽さを出している**
- **読後感:** 笑い・温かさ・少しの切なさ。官僚的なルール(ピザの食べすぎを防ぐ義務的な運動など)とピザのギャップで笑わせる。脚注で、亡くなった配偶者とよく分け合っていたピザの話が淡々と書かれ、切なさが出る
- **文体:** 製品スペックのような書き方(寸法、重さ)。試験結果は「対象 / 結果」の表で一行ずつ。脚注に補足と小さなユーモアを入れる
- **応用:**
  - 製品スペック表の冷静な文体でユーモアを出す
  - 多数の反応を表にしてデータとして膨らませる
  - **本文は冷たいデータ、脚注に感情を置く**

## 5本に共通する技法
1. 収容プロトコルや仕様を先に示し、ルールの外側に異常を置く。規則が細かいほど、結果の不条理が際立つ
2. 「入力 → 出力 → 考察」「対象 / 結果」の反復で事例を増やす
3. 事務的な報告文と極端な内容(死、奇跡、狂気)の落差で、笑いと怖さを同時に作る。死は感情を交えず一行で置く
4. 伏せ字は「最悪の結果」と「人名」にだけ使い、仕組みは「未解明」のまま残す
5. 本文は冷たいデータで書き、脚注や注記に感情を入れる。この温度差が読後感を決める
