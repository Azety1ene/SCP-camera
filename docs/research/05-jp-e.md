# SCP-JP(深く分析)E

出典:SCP財団 日本支部(http://scp-jp.wikidot.com/)、CC BY-SA 3.0。本ノートは技法の分析であり、引用は1文以内にとどめている。

## SCP-268-JP 終わらない英雄譚
- **基本:** Euclid。黒革表紙の本。危険な救命活動で亡くなった人に命を救われた人の前に現れる。本には24時間ごとに新しい章が追加され、各章で救命者は選択を迫られる。救命は必ず成功し、救命者は必ず死ぬ
- **構成:** 収容プロトコル → 説明(外見、出現条件、章の追加)→ 章の内容の例(折りたたみで6件)→ 最終章と改題 → 対策プロトコル → 財団が保有する本の抜粋
  - ルールを先に把握させ、事例で体感させる
- **伏せ方:** 章は6例だけを見せ、残りは想像させる。ある抜粋では「エージェントの叫びはすべて検閲されている」と書き、内容を隠して余韻を残す。**改題後の題名は伏せずに見せ、英雄譚から侮辱の題への反転を示す**
  - 原題:「病魔に苦しむ妹を救った、心優しき兄の英雄譚」→ 改題:「たった一人の肉親を見殺しにした屑野郎の物語」
- **読後感:** 怖さ、やるせなさ、皮肉。救命者の無償の死が繰り返されることと、改題によって世間の評価が反転すること。対策が「救命者を批判する本を出版させる」ことで、善行が嘲笑される構造を報告書に組み込んでいる
- **文体:** 推定の語尾が多い(「〜と思しき」「〜と考えられています」)。寸法・章数・年数が具体的
- **日本支部らしさ:** 救急・警察・消防という制度、地下鉄のホーム、フロント企業と民事訴訟という現実味のある処理
- **応用:**
  - 報告書の中に別の作品(本、手紙)を入れ子にし、その抜粋で物語を見せる
  - **タイトルや評価の反転で、同じ出来事の意味を変える**
  - 検閲で「何が書かれていたか」を見せない

## SCP-650-JP 人でなし、でく人形
- **基本:** Euclid。成人男性の姿をした肉体。会話も動作もできるが、生命反応はない。秒間286回の極小の現実改変で、人間らしい動作を「模倣」している
- **構成:** 収容プロトコル →説明(外見と身体検査 → 高速撮影 → 計測と機器の故障、職員の体調不良 → 模倣の仕組み → 出現の経緯 → 破壊の保留)。本人の陳述は別ページ
  - 「普通の人」に見える外見から始まり、数値を積み上げて正体に近づく
- **伏せ方:** **心の内は隠し、外に出る影響だけを数値で見せる。** 理解できないことの怖さが出る
- **読後感:** 不気味さと静かな恐怖。大きな破壊はない。「普通に見える人間が、実は動作を模倣しているだけ」という点と、破壊が恒久的に保留されているという手の出せなさ
  - 「SCP-650-JPからは生命反応は検出されず、一般的な死体と同様の反応を示しました。」
- **文体:** 感情を出さない報告書調。数値の精度が高い。日本支部の独自用語(ヒューム値、現実酔い)
- **応用:**
  - 数値を段階的に積み上げ、ありえなさに実在感を与える
  - 異常の正体を一語で説明し、「普通に見えること」自体を怖さにする

## SCP-243-JP 恩人へ
- **基本:** Safe。電源も回線もいらない押しボタン式の電話。過去に命を救われた人が受話器を取ると、命を救ってくれた人と5分間だけ通話できる。相手は過去の時点の人で、会話が現実を変える危険がある
- **構成:** 収容プロトコル → 説明(ルール、5分の制限)→ 実験A(医師と通話)→ 実験C(ライフセーバーと通話)→ 実験D(エージェントが消防士と通話し、過去を変えかける)→ 補遺(立ち会ったエージェントの手記)
  - 「ルール → 段階的な事例 → 最大の事件 → 手記で感情」。事例の関係性がだんだん深くなる
- **伏せ方:** 名前は伏せるが、**手記の中の台詞「大丈夫だぞ、█████」は名前を伏せたまま台詞として見せる。** 読者は名前を知らないまま、人物の温かさだけを受け取る。結果を断定せず、一人の解釈だけを示す
- **読後感:** 切なさ、温かさ、余韻。手記の締め「それにはどれほどの勇気がいるのだろうか。」が感情を一点に集める
- **文体:** 報告書は硬い文体。手記は一人称の常体で、感情が直接出る
- **日本支部らしさ:** 公衆電話、消防、海の事故といった身近な場面
- **応用:**
  - **「ルール → 事例 → 最大の事件 → 第三者の手記」の順**
  - 名前は伏せても台詞で存在を示す
  - 結果を断定せず、一人の解釈で締める

## SCP-100-JP 屋根裏部屋の宇宙
- **基本:** Keter(事件の後に格上げ)。古い木造家屋。屋根裏に入ると、外観と合わない無重力・真空の空間が広がり、木材の「惑星」と電球の「恒星」が浮いている。これを壊すと、実際の宇宙の天体にも影響する
- **構成:** 収容プロトコル(立入禁止、表向きは鉱山施設、建てられた年の建材と工法での補修手順)→ 廃止されたプロトコル(折りたたみ)→ 説明(外見 → 屋根裏 → 惑星と恒星 → 現実の宇宙との同期)→ 事件記録1(恒星の破壊が、後に超新星爆発につながる)→ 事件記録2(地震による倒壊。詳細は非公開。格上げ)
  - 外側(管理)→ 内側(空間)→ 宇宙規模の影響、と規模が広がる
- **伏せ方:** 事件記録2の詳細は「レベル5未満には非公開」。何が起きたかは見えず、格上げの重さだけが伝わる。基礎の数字(半径、年数)は隠さず、詳細と結果だけを伏せる
- **読後感:** 畏怖と静かな不安。古びた家屋の中の宇宙という対比、**事件の何年も後に超新星が起きるという遅れてくる影響**で、取り返しのつかなさが出る
  - 「木材――それは様々な家具を分解したあとの廃材のように見えます――」
- **応用:**
  - 管理手順 → 内部 → 外部への影響 → 事件、と規模を段階的に広げる
  - **廃止された旧プロトコルを残し、組織の歴史の厚みを出す**
  - 遅れてくる影響で、因果の怖さを作る
  - 日常の物(古い家、家具の廃材)と異界のスケールの対比

## SCP-120-JP 世界で一番の宝石
- **基本:** Euclid。知性を持つ巻き貝の貝殻。十分な価値を認める人がいないと、巨大な生物を放って高価な物を壊す。価値を認める少女が説得すると、生物は消える
- **構成:** 収容プロトコル(偽装博物館、少女との会話の手順、少女の教育と外出の規定)→ 説明 → 収容履歴の表 → 補遺(研究員の聴取:価値の見積もりの誤りが収容手順を変えた)→ 会話ログ → 少女が作った注意事項(注記付き)→ 補遺(貝が書いたとされる文章)
  - 「規定 → 性質 → 事実の表 → 人間側の失敗 → 会話(笑い)→ 注意事項(笑い)→ 手紙(切なさ)」。笑いを積んで、最後に感情を出す
- **伏せ方:** 伏せ字の使い方が場面で変わる。ゲームのタイトルを[データ編集済]にする箇所は伏せ字そのものが笑いになる。**最後の手紙は「最後の一行が線で消されていた」という注記で終わり、消された言葉が読者の想像に委ねられて切なさになる**
- **読後感:** 笑いから切なさへの転調。貝が「思い出の中の宝物」であり続けたいと書いた手紙で静かになる
  - 「きみはいつか大人になる。それを止めることはできない。」
- **文体:** 硬い報告書に「(注記:…)」が入り、淡々とした注記が笑いを作る。子どもの口調と貝の尊大な口調の対比。数値の桁が飛ぶ(価値の見積もりが1万円台から50億円へ)
- **日本支部らしさ:** ビンゴの景品、テレビゲーム、リコーダー、算数のテストといった身近な場面
- **応用:**
  - 厳格な規定と子どもの会話のギャップ
  - 注意事項を注記付きで並べて笑いを作る
  - **伏せ字を、笑いにも切なさにも使い分ける**
  - **最後に「消された一行」を置き、注記で締める**

## 共通する技法と日本支部らしさ
- 報告書の形式の中に、抜粋・補遺・手記・ログとして物語の本体を入れる
- 情報は「ルール → 事例 → 最大の事件 → 手記や補遺で感情」と積み上げ、最後に感情を一点に集める
- 伏せ字・検閲・非公開は、見えない部分を想像させる装置。恐怖・余韻・笑いのどれにも使える
- 地の文は常体・推定の語尾で冷静に保ち、感情は手記・ログ・注記に任せる
- 日本支部らしさは、身近な日常物(公衆電話、古い家、ビンゴ、テレビゲーム)と日本の制度(警察、消防、学校)
