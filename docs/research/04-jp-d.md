# SCP-JP(深く分析)D

出典:SCP財団 日本支部(http://scp-jp.wikidot.com/)、CC BY-SA 3.0。本ノートは技法の分析であり、引用は1文以内にとどめている。

## SCP-544-JP 孤独な放送室
- **基本:** Euclid。廃業した百貨店。3分ごとに「お知らせです。[A]さん、[B]さんがお待ちでした」という館内放送が流れる。呼ばれたBはAの記憶を失い、以後Aを知覚できなくなる
- **構成:** 収容プロトコル → 説明(建物、放送、放送室の扉)→ 調査記録(Dクラス職員の実況に近いログ)→ 追記(少女の保護)→ 追記(身元の特定と返還計画)→ 追記(返還の失敗)
  - ルールを先に示し、仕組みを体験ログで見せ、最後に事後報告で結末を確定させる
- **伏せ方:**
  - 人名は伏せ、**脚注で「D-1104の母親」など正体だけを書く**。誰かは分かるのに名前は見えないので、人間関係の重さが残る
  - 放送室の中は見えず、音声だけで示される
  - 「[2分間音声無し]」のような時間の表記が、省略の代わりに間を作る
- **読後感:** 切なさと怖さ。Dクラス職員が志願の動機を「忘れて貰えるなんて最高じゃねぇか」と軽く語り、後で後悔に変わる。博士の事務的な返事が、個人の感情を浮かび上がらせる
- **文体:** 説明は丁寧な公文書調。ログは博士が丁寧語、Dクラス職員が口語。私情は地の文ではなく会話に出す
- **日本支部らしさ:** 百貨店の「迷子のお知らせ」の定型文と、「ご来店頂き誠にありがとうございます」という店内放送の決まり文句を異常の媒体にしている
- **応用:**
  - **放送・アナウンスなど、日本の生活の定型文を異常の媒体にする**
  - 動機の軽さと結末の重さを対比させる
  - 固有名詞は伏せ、脚注で関係だけを補う

## SCP-062-JP 生存権
- **基本:** Keter → Neutralized。放棄された電波塔を中心に広がる認識災害。紙や画面で「判決文」のような文字列を見ると、数日で身体の一部が消えて死亡する
- **構成:** 収容プロトコル(無力化後の文言。旧手順は折りたたみ)→ 説明(判決文の例)→ 無力化計画1(失敗を表で記録)→ 無力化計画2(派遣1〜3回目の報告書)→ 再分類
  - 報告書ごとに要求クリアランスが表示され、読者の立場にも段階がある
- **伏せ方:** 2回目の派遣報告書は丸ごと[削除済]。**読めないこと自体が、作戦の凄まじさを伝える。** 隊員名はイニシャル
- **読後感:** 不条理な恐怖と皮肉な救済。最後の派遣で博士が自分自身と同じ顔の人物に「そんなに生き残りたいですか?」と問われる。結末は一行の断定で締まる。タイトルの「生存権」が、憲法上の権利と作中の論理の両方で回収される
- **文体:** 報告書ごとに筆者が違い、文体も違う(隊員は話し言葉寄り、博士は短く区切る)。判決文は法律文書の型だが、根拠が欠けている
- **日本支部らしさ:** 法律用語の転用(「生存権」)、日本の公的文書の型
- **応用:**
  - **公的文書の型(判決文、通知、規約)に、論理の欠けた内容を入れる**
  - 同じ出来事を、筆者を変えて別の温度で語らせる
  - 閲覧権限の表示で、読めない情報の存在を示す
  - 結末を一行の断定で締める

## SCP-161-JP 伊れない病
- **基本:** Keter。「伊る」という動作と概念の認識を奪う病。この言葉を聞くか、表音文字で見ると、数時間分の記憶を失う
- **構成:** 収容プロトコル(言葉を聞かせない、見せない)→ 説明(バレリーナや能の例)→ 実験記録(被験者と研究員の会話)→ 補遺(原因不明、患者は増加中、無形文化財の保存計画、今後の懸念)
- **伏せ方:** 黒塗りはほぼない。被験者の言葉が途切れること自体が伏せ字の役割を果たす。補遺で次に失われそうな別の言葉が挙がるが、説明されない
- **読後感:** 笑いと不気味さ。被験者の軽口で笑わせた後、「ド忘れ」と「このテストはまだ始まらないのか」の繰り返しでじわじわ怖くなる。能を「扇を持って舞台上を歩き回っているだけ」と平板に書き、認識が失われた状態をそのまま読者に見せる
- **文体:** 説明は学術的、実験記録は被験者が口語、補遺は公的報告の調子
- **日本支部らしさ:** **トリガーが「音」と「表音文字」であるという、日本語の文字の性質を使った仕掛け。** 能や無形文化財という日本の文化
- **応用:**
  - 日本語の音と文字の特性を仕掛けにする
  - 被験者が目的を忘れていく繰り返しで不安を作る
  - 最後に「次に失われるかもしれないもの」を示し、広がりを感じさせる

## SCP-1045-JP お眼鏡にはかなわない
- **基本:** 黒縁眼鏡をかけた女性教師が対象。文章に入り込み、赤ペンで添削し、青ペンで褒めるコメントを入れる。添削は一定時間内に直さないと、強制的に修正され範囲が広がる。現行版では「オブジェクトクラス」の欄が「担当クラス」に書き換えられている
- **構成:** 現行版(冒頭に大幅に添削された旨の注意)→ 基本情報 → 説明 → 追記 → 改訂前の版(折りたたみ)。**改訂前の版には教師による添削コメントが35個付いている。** 記事そのものが添削された文書という入れ子構造
- **伏せ方:** 最も多層的。黒塗り、折りたたみ、そして**添削者が「個人情報なので削除しましょう」と指示するメタ的な伏せ**。手紙の文面も削除の指示を受けながら断片が残り、読者は指示と本文の隙間から教師の感情を読み取る
- **読後感:** 皮肉な笑いから悲哀へ。添削者の突っ込みで笑わせた直後に、恨んでいないと書かれた手紙が来る。題名が「眼鏡」と「審査に通らない」の二重の意味
- **文体:** 学級作文の添削。添削者は「〜ましょう」「〜してくださいね」の柔らかい口調で、顔文字も使う
- **日本支部らしさ:** 学校の文化(職員室、学級委員、朝学活、合唱コンクール、卒業式)、言葉遊びの題名
- **注意:** 手紙の内容はいじめや自殺を連想させる。このアプリの生成では、自殺・自傷・いじめを題材にしないよう制限する
- **応用:**
  - **本文に添削・注釈を重ね、二つの声(本文の声と注釈者の声)を作る**
  - 黒塗りの指示そのものを笑いにし、その下に感情を残す
  - 「見せてから隠す」(改訂前の版)で、読者に秘密を発見させる
  - 言葉遊びの題名

## SCP-240-JP 0匹のイナゴ
- **基本:** Euclid。死ぬと「死んだ」という事実を消してしまうイナゴ。収容後に何匹も死んでいるが、個体数は「0匹」のまま
- **構成:** 収容プロトコル(データ破損)→ 説明(死亡時の特異性、個体数)→ 発見の経緯(山中の無許可施設)→ 回収された文書(要注意団体の「開発資料」フォーマット)→ 補遺(無力化への再分類の検討、文書の矛盾の指摘、本当の性質の推測)
  - 公的な文書を見せ、その矛盾を補遺で暴く順
- **伏せ方:** **数値の欠落そのものが異常を示す。** 対象名と死亡数に[データ破損]が入り、「記録は欠けているのに個体数は0と書かれている」違和感を作る。担当者は「どう管理していたか思い出せない」
- **読後感:** 謎解き的な不条理とじわりとした怖さ。「2匹を工具で破壊したところ、総数は変わらず0匹であった。」の反復でニヤリとさせ、最後の「誰も違和感を持たなかったのだろうか?」で「誰も気づかなかった」怖さに変わる
- **文体:** 開発資料の型(「プロジェクトナンバー」「開発要件」「開発結果:開発は成功。」と体言止め)
- **応用:**
  - **管理票・開発資料などのフォーマットで、本物の文書らしさを作る**
  - 数値の欠落を異常の一部にする
  - 小さな違和感を伏線にし、補遺で全体を反転させる
  - 「誰も覚えていない」を結末にする

## 共通する技法と日本支部らしさ
- 5本とも、公的文書の型(収容プロトコル、報告書、判決文、開発資料、添削)を借りて、異常な内容を入れている
- 黒塗り・削除・閲覧権限・改訂前の版といった「見せ方の制限」が、読者の想像を引き出す
- 結末は一行の断定か、事後の記録で締め、不条理を確定させる
- 日本支部らしさは、**日本の生活と制度に根ざした題材**(百貨店の放送、学校の添削、無形文化財、法律用語)
- 日本語特有の仕掛け(表音文字がトリガー)と、言葉遊びの題名
