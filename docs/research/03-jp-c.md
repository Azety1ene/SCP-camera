## SCP-2000-JP 伝書使
- **基本:** Thaumiel。ネットワーク上で動く情報知性体で、イヌのような見た目のGUIを持つ。セキュリティの穴を「掘って」侵入し、情報を「巣」に持ち帰る。その際に情報を「噛んで」しまい、文章は残るが数値や日付が壊れやすい。知能は5歳児程度
- **構成:** 項目(収容プロトコル、説明)→ 旧い財団から「新たな財団職員」へのメッセージ → 研究員同士のやり取り、知性体の訓練ログ(ひらがなの子供口調)、閲覧禁止の通達 → 「世界は明日滅びる」→ 翌日「何もなかった」→ 改訂された収容プロトコル
  - ページが「接続が切断されました」の画面で区切られ、続きが段階的に開く
- **伏せ方:**
  - SCP番号や名前を**文字化け**させる。設定上の「噛む」破損を、読者が見た目で体験する
  - 収容プロトコルを版ごとに書き換え、状況の変化を見せる(「未収容」→「対話による収容」)
- **読後感:** 終末ものの緊迫感 → 無垢な語りと終末の重さの落差による不穏な笑い → 穏やかな温かさと切なさ
  - 「もう必要ないんだ。世界は明日滅びるんだから。」
- **文体:** 本体は報告書調。知性体の台詞は平仮名が多い子供口調(「ぼく」「だよ」「ほんとに?」)。研究員の私情は台詞に滲む
- **応用:**
  - 日付や型番を、作中の設定として「信頼できない」ものにする(わざと壊れた数値を書く)
  - 文字化けや欠落を、対象の性質として扱う
  - **収容プロトコルを版ごとに書き換え、時間経過や結末を示す**
  - 無垢なキャラクターに重い事実を語らせる

## SCP-040-JP ねこですよろしくおねがいします
- **基本:** Safe。旧村にある木造の井戸小屋。中を肉眼で見た人は「ねこが居た」と報告し、以後、猫を「毛がなく、人の目が二つある存在」として認識するようになる。暗い所で「ねこ」に見られている感覚が生じる。この観念は他人に伝わる(ミーム)
- **構成:** 収容プロトコル(直接見るのは禁止、カメラ越しのみ、Dクラス職員のみ)→ 説明(小屋の寸法、井戸、事案の経緯)→ 警告ブロック(「ロック解除」ボタン。閲覧にはミーム対策が必要)→ 異常性の詳細 → 伝播の説明 → 「文章ここまで」→ インシデントレポートと脚注
  - **読み進めると、「ねこはいます」「これはねこです」といった文が本文に割り込んでくる。** 読者自身が「ねこ」を読まされる構造
- **伏せ方:** 事案の詳細・地名・年は伏せる。一方、**「ねこ」という言葉は伏せられず、むしろ繰り返される**。伏せる語と繰り返す語が反転している
- **読後感:** 認識異常の不気味さ → 本文への割り込みによる笑いと不安 → 末尾の「よろしくおねがいします」で脱力する笑い → 最後のレポートで「読んだ人が被害者」と分かる二重の怖さ
- **文体:** 事務的な受動態(「〜と推測されています」「〜が報告されています」)。寸法などの数値は具体的
- **日本支部らしさ:** 旧村、井戸、山村の怪談の空気、サイト番号(-8120)、和風の処置名
- **応用:**
  - 「見てはいけない」規則を具体的に書く(カメラ越し、Dクラス限定)
  - **報告書の本文に、異常による割り込みや誤字を入れ、汚染を表現する**
  - 報告書の読み手が被害を受けるメタ構造
  - 地名を伏せ、地域の怪談として読ませる

## SCP-444-JP █████[アクセス不許可]
- **基本:** オブジェクトクラスは「割り当てられていない」。ある人物たちの血液が付着した紙媒体が分類されている。対象は「奴」と呼ばれる
- **構成:** 冒頭の閲覧警告(手順を踏まずに閲覧した者は抹殺の対象)→ 端末風のアクセスログ → 書き手による告白のような本文(収容の失敗、施設の放棄、「奴」の正体の推測、「手遅れ」の宣告)→ 署名は[削除済]
  - 警告で入り、本文で「既に手遅れ」と告げ、書き手の消失で閉じる
- **伏せ方:**
  - タイトル自体を伏せる
  - 「奴」の能力は書かない。書き手が「把握できなかった」と認めることで、省略が無力さの表現になる
  - **クラス未割当と明記し、情報が無いこと自体を見せる**
  - 署名を[削除済]にして、書き手の消失を示す
  - 地下130m、サイト番号などの場所と手続きの数字だけは具体的に出す
- **読後感:** 怖さ、絶望、静かな後悔。「読んでいる時点で手遅れ」という逆説が決め手
  - 「もう二度と、失敗を繰り返さないでください」
- **文体:** 警告は命令形。本文は一人称「私」と二人称「あなた達」で、推量が多い(「〜でしょう」「〜思いたい」)。私情が強い
- **応用:**
  - 冒頭の閲覧警告やアクセスログの形式で、「見ること」そのものを物語にする
  - 対象を名付けず「奴」のような代名詞で呼ぶ
  - 署名や書き手を[削除済]にする

## 共通する技法と日本支部らしさ
- 報告書の形式は崩さず、欠落や伏せ字で恐怖と人物像を作る
- 伏せ字は「何を消すか」より「どう消すか」が大事。██、[編集済]、[削除済]、文字化けを使い分ける
- 読むこと自体に読者を巻き込む(警告、ロック解除、閲覧禁止)
- 職員の私情は少なく、末尾の一行や脚注に滲ませる
- 日本支部らしさ:和風の題材(旧村と井戸、焚書)、サイト番号(-81XX)、ひらがなの多用
