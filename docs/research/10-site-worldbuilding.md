# サイトとしての世界観の作り込み方(界隈の研究のまとめ)

`11`〜`15` の調査をもとに、カメラ以外の部分で世界観を作り込む方針をまとめる。

## 研究から分かった、SCPらしさの核
1. **組織の手触り:** 財団は「確保・収容・保護」を掲げ、情報を「知る必要性」で細かく区切る官僚組織。施設、部署、部隊、職員分類、文書の様式がすべて決まっている(`11`)
2. **無味乾燥な文書が怖い:** 残酷な描写ではなく、事務的に書かれていることが恐怖を生む(`15`)
3. **読めないこと自体が物語になる:** 黒塗り、閲覧制限、パスコード、折りたたみ。Wikiのページデザインもこの演出のために発達している(`14`)
4. **事務文書のパロディが定番:** 新人研修のシラバス、説明書、事例集といったTaleの形式は、SCP報告書と並ぶ人気の形式(`13`)
5. **日本支部らしさは「日常と制度」:** 「81」は日本の国際電話番号に由来し、食堂・購買・託児所が描かれる。部門名は行政用語や仏教語で、機動部隊はひらがなで呼ぶ(`12`)
6. **共有世界とクレジットの文化:** 唯一の正典はなく、作者ごとのカノンがある。CC BY-SA の表示と「非公式」の明記が必須(`13` `15`)

## このサイトの設定(独自カノン)
- このサイトは、財団日本支部の **統合観測ネットワーク** の職員用端末
- 利用者は、新設の観測所に配属された新人職員。所属部門は、日本支部の部門の発想を借りたオリジナルの「**観測記録部門**」
- 既存のキャラクター・要注意団体・カノンは登場させない。借りるのは仕組み(命名規則、クリアランス、文書の様式)だけ

## 作るもの

### 1. 財団ポータル(認証後のホーム)
- 所属(観測所 81-OP-██、サイト-81██、観測記録部門)、職員分類、クリアランス
- **財団内報:** 日常と異常が混ざったニュースが流れる(「サイト-81██食堂、木曜の献立をカレーに統一」「先週の収容違反警報は誤報でした」など)
- 「知る必要性の原則により、表示される情報は制限されています」の帯
- 根拠: 組織の手触り(1)、日本支部の日常(5)

### 2. 職員証(IDカード)
- 職員番号、職員分類、所属部門、クリアランス、有効期限
- 顔写真を撮ると、自動編集で顔が[編集済み]になる(実装済みの顔認識を流用)。「自分の職員証の顔が黒塗り」という体験
- 根拠: ページデザインのIDカード部品(3)

### 3. 書庫(読み物の文書)
カメラを使えない人でも楽しめる読み物。Taleの定番形式で、すべて書き下ろす。
- 『統合観測端末 取扱説明書(新任職員向け)』
- 『観測記録部門 事故事例集』
- 『新任職員オリエンテーション資料』
- 『サイト-81██ 食堂だより』
- 文書ごとに必要なクリアランスを決め、足りない文書は黒塗り・ACCESS DENIED・パスコードで閉じる
- 根拠: 事務文書パロディ(4)、読めないことが物語(3)

### 4. クリアランスの昇格と受信箱
- 収容した件数でレベル2 → 3 → 4と昇格し、読める文書と黒塗りが増えていく
- 昇格や節目の出来事は、**社内メール**(差出人・宛先・件名付き)で受信箱に届く
- 書庫の文書の中に、別の文書のパスコードを隠しておく(SCP-245の「操作して開く」発想)
- 根拠: 読めないことが物語(3)、体験型の派生作品(`15`)

### 5. 報告書の作り込み
- 冒頭に **ACSの帯**(収容・撹乱・リスクの3軸)と **CLASSIFIED スタンプ**
- Wikiの文化に合わせた「好き / 好きじゃない」の評価ボタン(端末内に保存)

### 6. 入口と信頼
- **「はじめての方へ」ページ:** SCPを知らない人向けに、一言の説明、遊び方、非公式であることを書く
- **ライセンスの強化:** 規約ページを、TASL形式のクレジット、「非公式」の明記、サイトの文章を CC BY-SA 3.0 で公開する旨、AIによる生成であることの明記、に書き直す

### 7. 小さな仕掛け
- 世界観に合わせた404ページ、タブを離れたときのタイトルの変化、コピー時の警告、まれな収容違反警報、季節・時間帯による変化

## 進める順番の案
1. **6(入口と信頼)**:公開中のサイトなので、ライセンスまわりは最優先で直す
2. **1(ポータル)+ 2(職員証)**:サイトの「顔」になる
3. **3(書庫)**:読み物を3〜4本
4. **4(昇格と受信箱)**:進める楽しさ
5. **5・7**:仕上げ
