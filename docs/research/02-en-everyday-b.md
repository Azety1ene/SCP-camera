# EN翻訳版(深く分析)B:日常の物

出典:SCP財団 日本語Wiki(http://scp-jp.wikidot.com/)、CC BY-SA 3.0。本ノートは技法の分析であり、引用は1文以内にとどめている。

## SCP-1048 ビルダー・ベア
- **基本:** Keter。高さ約33cmの、自律して動くテディベア。人に愛情を示す一方で、耳・幼児の手足・錆びた金属などで作った暴力的な「創作物」を生み出している
- **構成:** 収容プロトコル(サイト内を自由に歩き回っている、と安全を宣言したうえで行方不明と述べる)→ 博士の引用 → 説明(愛らしさ → 意思疎通の失敗 → 創作物の仮説)→ 創作物A・B・Cの事件 → 補遺(SCP-2295との対比)→ 締めの注意
  - 「かわいい → 安全 → 裏切り」の順。冒頭で安全を断言してから覆す
- **伏せ方:** 日付・人数・研究者名・[データ削除]。死因と被害の範囲は具体的に出す。創作物Bの素材は「明かされない」と書き、読者に推測させる
- **読後感:** 恐怖とボディホラー。愛らしさと創作物の残酷さの落差が決め手。Dクラスにまで懐くという一文が、後の裏切りを強める
- **文体:** 「〜と思われています」「〜という仮説が立てられています」など不確かさを示す語尾が多い。数値は具体的(約33cm、5m以内、20秒たらず、3分以内)。職員の私情は博士の悪態まじりの引用に出る
- **応用:**
  - 愛らしい描写を先に置き、後で異常を明かす
  - 被害の範囲は距離・時間で数値化し、人数や固有名詞は伏せる
  - 「仮説」「不明」の語尾で説明を切り、余白を残す

## SCP-1609 椅子の残骸
- **基本:** Euclid。椅子の残骸。座りたい人の元へテレポートしてくる。暴力的に扱われると、相手の肺の中に部品を転送して殺す。GOCに破壊されて以降、こうなった
- **構成:** 収容プロトコル(花壇の根覆いとして使う、美しさを褒める、私服を着る、モーター禁止、など細かい手順)→ 説明(構成 → 能力 → 暴力反応の引き金 → 元の椅子 → GOCによる破壊)→ 文書1609-1(博士の訓話)
  - **奇妙な手順を先に見せ、理由は後で明かす**順序
- **伏せ方:** 日付・重量・距離・回数は伏せる。一方で、暴力反応を引き起こす言葉や服装、モーター音は具体的に列挙し、「何をしたら危険か」は読者に分かるようにしている
- **読後感:** 不気味さ、ブラックユーモア、そして哀しさ。「無害なもの → 人間の介入 → 危険なもの」という因果と、末尾で「本当は保護を求めている」という見方に転換するところが決め手
- **文体:** 手順は「〜してください」「〜なければなりません」の義務形。説明は「〜ことが分かっています」と淡々としている。文書は一人称の語りで、語り手の思想がはっきり出る
- **応用:**
  - 規則の体裁を使って、世界観とユーモアを出す
  - **理由を後から明かす「因果の遅延」**
  - 最後の文書で評価や思想を示し、読者に解釈の余地を残す

## SCP-2295 パッチワークのハートがあるクマ
- **基本:** Safe。パッチワークのぬいぐるみのクマ。臓器を損傷した人の近くで動き出し、布と糸で臓器の模造品を縫い上げて本物と入れ替える
- **構成:** 収容プロトコル → 説明(外見 → 動き出す条件 → 治療の仕組み → 材料の補充)→ 実験ログ4件 → 補遺(発見の経緯、見舞いカード)
  - 「安全なぬいぐるみ → 善意の治療 → 具体例 → 私的な品で締める」の順
- **伏せ方:** ほとんど伏せない。分からない点は「分かっていません」と明示して残す
- **読後感:** 切なさと温かさに、少しの不気味さ。淡々とした実験記録と、患者の感謝や涙の対比が決め手。最後の手紙で感情が完成する
- **文体:** 医療報告のような「〜が確認されました」「〜が観察されました」。数値が多く、信頼感を生む。職員の私情はほとんどなく、感情は患者の証言で出す
  - 締めの一文:「全ての傷を癒す事が出来るのは、時間だけだから」
- **応用:**
  - 冷静な報告書の文体に、温かいエピソードを混ぜて温度差を出す
  - 実験ログ形式で小さな事例を並べる
  - **最後に私的な品(手紙、カード)を置いて感情を締める**

## SCP-1471 MalO ver1.0.0
- **基本:** Euclid。無料のスマホアプリ。入れるとアイコンは出ないが、数時間ごとに画像が届く。時間が経つと、持ち主の周囲に人型の存在が写り込むようになり、やがて肉眼でも見えるようになる。見えるようになると元には戻らない
- **構成:** 閲覧制限の表示 → 収容プロトコル → 説明(アプリの概要 → 画像の段階的な変化 → 肉眼で見えるようになる → 唯一の予防法)→ 保存文書(アプリストアの掲載文)
  - 「普通のアプリ紹介 → 段階的なエスカレーション → 製品文書で締める」の順
- **伏せ方:** 献辞の宛先を伏せる。存在が危害を加えるかは「現在のところ報告はない」に留める。閲覧制限の表示で、読者が「覗いている」感覚を作る
- **読後感:** じわじわ来る不安。広告文の甘い言葉が、「参加するほど近付いていく」という一文で不穏に反転するのが決め手
  - 「あなたが参加すればするほど、MalOはあなたに近付いていく」
- **文体:** 「24時間経つと」「48時間経つと」「72時間経つと」と段階を反復する。広告文だけ口語で軽い
- **応用(このアプリに最も直接使える):**
  - **写真の背景・反射・端に、異常が「写っている」と書く。** 読者が自分の写真を見直したくなる
  - 時間経過による段階的なエスカレーション
  - 現代の製品文書(商品説明、広告、取扱説明書)を資料として挿入し、日常感を出す
  - 予防法を一つだけ示す

## SCP-1981 "演説中に解剖されるロナルド・レーガン"
- **基本:** Safe。ビデオテープ。再生すると演説映像が映るが、途中から内容が逸脱し、演説者の体が切り刻まれていく。再生のたびに内容が変わる
- **構成:** 収容プロトコル → 説明(外観 → 発見 → 元の演説 → 異常化 → 再生ごとの変化 → 謎の人物)→ 再生記録(年代順)→ 編集済みの記録(高クリアランスを要請)→ 最後の映像 → 注記
  - 資料の公開範囲が段階的に狭まり、最後に映像が「見ている」側へ反転する
- **伏せ方:** 暴力的な描写は[編集済]。ある年の記録は丸ごと「クリアランスLevel05を要請」で隠す。一方で、謎の人物の出現と最後の文字は見せる。**隠されるほど怖さが増す**設計
- **読後感:** 不快感と不気味さ、政治風刺。最後の一文で視線が読者に向くのが決め手
- **文体:** 説明の合間に、再生記録のト書き([拍手]、[笑い声])を挟む。数値は具体的(日付、再生開始からの秒数、停止時刻)。報告者の感想が「興味深い事に」などで少しだけ出る
- **応用:**
  - 同じ条件でも毎回結果が違う、という反復と変化
  - **閲覧クリアランスで記録を段階的に伏せる**(このアプリのO5機能とそのまま重なる)
  - 最後の一文で、読者を「見られている側」に立たせる

## 5本に共通する技法
1. **安全宣言とギャップ:** 冒頭で「害はない」「安全」と示し、後で異常を明かす(1048、2295、1471、1981)
2. **不確かさを示す語尾:** 「仮説」「不明」「と見られています」で説明を切り、余白を残す(全記事)
3. **数値の具体化と伏せ字の併用:** 時間・距離・回数は具体的に書き、人数や固有名詞は伏せる(全記事)
4. **資料を重ねる:** 実験ログ、文書、製品の掲載文、再生記録など、別の形式の資料を挟む(2295、1609、1471、1981)
5. **最後に私的な要素で締める:** 手紙(2295)、職員の思想(1609)、視線(1981)
